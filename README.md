# powerbi-retail-dashboard
Power BI retail performance dashboard using sales and category data
Power BI Retail Performance Dashboard
# Overview

This project is an interactive Power BI retail performance dashboard built to analyse sales, stock, and category-level trends for a retail business. It was developed using Power BI Desktop and focuses on the types of KPIs that are typically used in everyday retail reporting and decision-making.

The main aim of the dashboard is to show how raw transactional data can be cleaned, modelled, and turned into clear, actionable insights that help monitor store and category performance.

# Business Questions Addressed

The dashboard is designed to help answer practical questions such as:

How are overall sales performing over time?

Which product categories contribute the most to total revenue?

How does performance change across different reporting periods?

Are there any early signs of declining sales or underperforming categories?

Key KPIs Tracked

Total sales

Sales trends over time

Category-wise contribution to revenue

Performance comparisons across reporting periods

Tools & Technologies

Power BI Desktop

DAX for calculated measures and KPIs

Data modelling using relationships between sales and supporting dimension tables

# Dashboard Features

Interactive filters and slicers to support time-based analysis

KPI cards for quick, high-level performance checks

Category-level breakdowns to enable deeper exploration of results

A clean and simple layout focused on readability and ease of use

# Data Notes

The dataset represents retail sales data structured specifically for analytical purposes.

Basic data cleaning and transformation were carried out directly within Power BI.

This dashboard is intended for analysis and learning rather than live production use.

# How to View the Dashboard

Download the .pbix file from this repository.

Open it using Power BI Desktop.

Use the slicers and visuals to explore trends and performance insights.

Note: This dashboard was built using Power BI Desktop and is shared via GitHub as a portfolio project. It has not been published to Power BI Service.
